# 📊 Employee Analytics Dashboard

An Employee Analytics Dashboard built with **Python, Pandas, and Matplotlib** to analyze employee data and visualize key insights. The dashboard provides an overview of employee performance, salary trends, department-wise salary distribution, gender distribution, and city-wise employee count.

---

## 📌 Project Overview

This project reads employee data from a CSV file, performs basic data analysis using **Pandas**, and presents the results through different visualizations using **Matplotlib**.

The goal of this project is to practice data analysis and dashboard creation using Python.

## 🚀 How to Run

Clone the repository

```bash
git clone https://github.com/umredkarkunal1-star/Employee-Analytics-Dashboard.git
```

Install the required libraries

```bash
pip install pandas matplotlib
```

Run the project

```bash
python dashboard.py
```
